  How to measure on an iPhone
  
    
    
  1. iPhone: Settings → Apps → Safari → Advanced → turn on Web Inspector.
    2. 
    
  2. Connect the iPhone to the Mac with a cable. On the Mac: Safari → Settings → Advanced → Show features for web developers.
    3. 
    
  3. Open this page on the iPhone. On the Mac: Safari → Develop → (your iPhone) → this page.
    4. 
    
  4. In Web Inspector: Timelines → enable Memory → press record (●).
    5. 
    
  5. On the iPhone, press a Load button and wait for "ready". Stop recording and note the peak and the level after loading.
    6. 
    
  6. Press Stop worker, reload the page, and repeat with the other method.
